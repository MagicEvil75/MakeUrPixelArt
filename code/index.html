Pixelizer

Image source

Vous pouvez aussi glisser-déposer ou coller (Ctrl+V) une image. Les pixels transparents restent transparents.

Résolution

La hauteur s’ajuste automatiquement aux proportions de l’image.

Rendu

Part minimale de pixels opaques dans un bloc pour qu’il reste visible.

Pipettes guides

Cliquez sur l’image originale pour poser une pipette. Glissez-la pour la déplacer, double-cliquez pour la supprimer.

Plus c’est haut, plus un petit détail de la couleur d’une pipette est conservé dans le pixel.

Déposez une image ici ou cliquez pour parcourir · Ctrl+V pour coller PNG, JPG, WebP, GIF, SVG… (la transparence est conservée)

Outils

Édition
